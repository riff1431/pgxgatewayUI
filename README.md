# pgxgatewayUI

Next-gen cyberpunk / neo-fintech payment gateway frontend built with **React 19**, **Vite**, **TypeScript**, **Tailwind CSS v4**, and **Shadcn UI**.

---

## Features
- **3-Step Merchant Registration Wizard**:
  - Step 1: Account & Contact Information (dual-chamber input layout with WhatsApp/Telegram/Password visibility toggle)
  - Step 2: Business & Processing Information (8 metrics & industry categories)
  - Step 3: Verification & Documents (interactive document upload simulation & legal consent)
- **Merchant Portal Dashboard**:
  - Glowing sidebar with active state and notification counters
  - Realtime Application Status stepper (`Under Review`)
  - Processing Offer metrics card (`2.9% + $0.30`, `$250,000 Volume`, `Daily Settlement`, `5% Reserve`)
  - 4 quick-action interactive tiles
- **3D Visual Ornaments**:
  - Tilted holographic credit card with gold EMV chip and planetary orb
  - 3D laptop with glowing keyboard reflection and verified checkmark
  - 99% Approval Rate crest badge with golden laurel wreath
  - Bottom "Industries We Approve" ticker

---

## Tech Stack
- **Framework:** React 19
- **Bundler:** Vite 8 (`@tailwindcss/vite`)
- **Styling:** Tailwind CSS v4 + Shadcn UI + Lucide Icons
- **Routing:** React Router v7 (`react-router-dom`)
- **Type Safety:** TypeScript 5.8

---

## Getting Started

```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Build for production
npm run build
```
